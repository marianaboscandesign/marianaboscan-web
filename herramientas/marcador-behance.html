Marcador «Copiar imágenes»

1. Arrastra este botón a tu barra de favoritos:

Copiar imágenes de Behance

2. Abre tu proyecto en Behance y pulsa el favorito. Aparece un cuadro con el contenido: pulsa «Copiar todo».

3. En GitHub: Add file → Create new file, nombre data/imagenes/ID.json, pega y Commit.
